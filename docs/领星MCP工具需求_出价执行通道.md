# 领星 MCP 工具需求：广告出价/预算执行类

> 提交对象：领星开放平台 / MCP 服务团队
> 提出方：Gordon（英国站广告决策自动化项目）
> 日期：2026-11-14
> 状态：待提交

## 一、背景与用途

我们在领星 MCP 之上构建了广告决策自动化链路：AI 基于广告数据生成优化建议 → 本地引擎三关校验 → 人工审批（已建 Web 审批门）→ **AI 会话经领星 MCP 执行修改**（执行方案回到 agent：agent 读取已批动作，通过领星 MCP 工具面直接执行，回执写回本地决策库）。

执行环节依赖领星 MCP 的 write 工具。目前链路可自动执行「加否定词、加关键词、创建活动」类动作，但**最高频的建议类型是关键词/投放出价调整与活动预算调整，MCP 暂无对应工具**，导致多数已批建议只能人工回后台操作。

## 二、现状盘点（2026-11-14 实测）

经 `help` 分页拉取 MCP 全量业务工具：**150 个 = 127 read + 23 write**。

23 个 write 工具中与广告相关的是：创建类（SP/SB/SD 活动组/组/广告）、SP 关键词添加、SP 否定关键词/否定投放添加与归档。**没有修改/调整类工具**（出价、预算、状态、广告位竞价均缺）。

## 三、需求清单（按优先级）

底层开放能力已具备对应场景（领星 ERP 内已有批量调竞价、调预算等功能；具体开放接口名与参数以贵方文档为准），**需求实质是把已有能力包装为 MCP write 工具**。

| 优先级 | 建议 toolId | 对应能力 | 典型用途 |
|---|---|---|---|
| P1 | `advertising_update_sp_keyword_bid` | 调整 SP 关键词出价（单/批量） | 决策链最高频动作：ACOS 超标降出价、有转化词提出价 |
| P1 | `advertising_update_sp_campaign` | 修改 SP 广告活动（预算/竞价策略/状态） | 预算追加、超投暂停、日活动预算控制 |
| P2 | `advertising_update_sp_target_bid` | 调整 SP 商品投放出价 | ASIN 定向出价调整 |
| P2 | `advertising_update_sp_adgroup` | 调整 SP 广告组（状态/出价） | 广告组级启停与统一调价 |
| P3 | `advertising_update_sb_*` / `advertising_update_sd_*` | SB/SD 活动、关键词、投放修改类 | SB/SD 建议执行 |

## 四、对工具形态的期望（与现有 write 工具保持一致）

1. 走标准链路 `help → search → action`，提供完整 `inputSchema`；
2. 保留 `approvalDisplay` / `successRule` 机制：若服务端有审批闸，返回审批凭证供 `approval_status` 查询；
3. 每次执行可在「广告操作日志」接口（`ad_operation_log_standard`）留痕可查；
4. 批量与单条均支持（决策链单次建议通常 1–10 条调整）。

## 五、我方信息

- 站点：UK（GBP）；店铺已授权广告数据（`ad_auth_shops` 可查）；
- 调用方式：ZCode / AI 会话经 MCP 工具面调用，动作留痕在本地决策库（提案→审批→动作→回执→观察→验收）；
- 数据安全承诺：凭证不入库不入日志，执行回执全量留痕。
